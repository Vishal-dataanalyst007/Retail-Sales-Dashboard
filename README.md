# Retail-Sales-Dashboard
🔹 Project Overview
This project demonstrates an end‑to‑end Data Analyst workflow using SQL, Python, and Power BI.
It analyzes retail sales, customer behavior, and product performance to deliver actionable business insights.

🔹 Tech Stack
SQL (MySQL) → Data cleaning, joins, analytical views

Python (Pandas, NumPy, Matplotlib, Seaborn) → Exploratory Data Analysis (EDA)

Power BI → Interactive dashboards, KPIs, trend analysis

GitHub → Project documentation & portfolio showcase

🔹 Dataset
Database: retail_db  
Tables:
customers
products
tables
Views created:
v_sales_enriched
v_revenue_summary
v_customer_summary
v_sales_trend_daily

🔹 Workflow
Data Preparation
Imported raw CSVs into MySQL retail_db
Created SQL views for automated reporting
Exploratory Data Analysis (Python)
Cleaned data with Pandas
Visualized trends with Matplotlib & Seaborn
Dashboard Development (Power BI)
Built KPIs: Revenue, Profit, AOV, CLV
Designed dashboards: Executive, Sales, Customer, Inventory, Marketing

🔹 Dashboard Layout
Executive Overview: Revenue, Profit, Margin %, AOV, Customer Growth

Sales Dashboard: Daily/Monthly trends, Top products, Channel performance

Customer Dashboard: Acquisition source, Churn, Demographics

Inventory Dashboard: Stock levels, Turnover, Reorder alerts

Marketing Dashboard: Campaign ROI, Conversion rates

🔹 Key Insights
Revenue grew 18% YoY, driven by online sales

Top 5 products contributed 40% of total revenue

👥 Customer churn reduced by 12% after targeted campaigns

📦 Inventory turnover improved by 15% with optimized stock management
